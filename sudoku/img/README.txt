数独 · img 素材说明
========================================

目录内容
----------------------------------------
1.png  2.png  ...  9.png
    游戏里 1~9 的贴图。棋盘上的数字、底部键盘上的数字都用这一套（同一份文件，画两处）。

命名规则
----------------------------------------
文件名必须**正好等于它代表的数字**（1.png 就是 1）。缺一张、坏一张都没关系 ——
那一张会自动退回内置的矢量数字，不会白屏、不会报错、不会出现破图。

素材要求
----------------------------------------
· 透明底 PNG（重要：白底图会在角色周围带一个白方块）
· 正方形或竖长方形，角色上下基本顶格
· 分辨率越高越好（当前这套是 121×149）

游戏里怎么缩放
----------------------------------------
· 棋盘上：等比缩放，高 = 格子边长 × DIGIT_RATIO（默认 0.80），以格心居中绘制
· 键盘上：等比缩放，高 = 按键高 × 84%（在 .pad .key img 的 CSS 里）
两个值都在 index.html 里搜 "数字贴图" / "key img" 就能找到，嫌小调大、嫌挤调小。
**候选数（笔记）那排小字始终是矢量绘制**，因为那个尺寸（约 10px）贴图会糊成一团。

想换成自己的图
----------------------------------------
1. 图本来就是透明底（推荐）：直接覆盖成 1.png ~ 9.png，刷新页面即可。

2. 图是白底不透明的：先体检，再用 bricks 目录里的脚本去白底（**用从四边洪水填充，
   不会把被身体包住的眼白抠出洞**）：

     cd C:\Users\30227\Desktop\games
     node bricks\.timg.js sudoku\img\1.png                              # 体检：透明占比 / 四角 alpha / 包围盒
     node bricks\.timg.js --clean sudoku\img\1.png sudoku\img\1c.png    # 去白底
     node bricks\.timg.js --preview sudoku\img\1c.png %TEMP%\p.png 2a4a3a   # 叠深色底肉眼验收有没有残留白边

   确认干净后把 1c.png 改名覆盖 1.png。9 张都要走一遍。

（改图后建议跑一次自测：node sudoku\.tsudoku.js —— 会校验贴图的等比缩放、格心居中、
  素材与数字一一对应、以及"某一张挂掉时只有那一张退回矢量数字"。）

不要放的东西
----------------------------------------
不要放 .psd / 工程文件 / 多套备选图。这一整个目录会随游戏一起发布，
目录里的每个文件都会被浏览器下载。原图建议另存到别处。
