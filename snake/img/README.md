# 图片皮肤替换说明

## 一、换图三步走

1. 把你自己准备好的 4 张图片**改名**成下面这几个名字：

| 文件名         | 对应部位 | 建议画布 | 说明 |
| -------------- | -------- | -------- | ---- |
| `head.png`  | 蛇头     | 128×128  | 图片默认**朝右**，游戏会自动按前进方向旋转 |
| `body.png`  | 蛇身     | 128×128  | 中间每节都用它 |
| `tail.png`  | 蛇尾     | 128×128  | 默认**朝右**，即粗的一头朝前、尖的一头朝后 |
| `apple.png` | 苹果/食物 | 128×128  | 固定不旋转 |

2. 直接覆盖 `snake/img/` 里现在的同名文件。
3. 刷新页面即可生效（浏览器可能缓存图片，用 `Ctrl+F5` 强制刷新）。

> 支持 PNG / JPG / WEBP / SVG（改成对应后缀，并同步改下面的文件名配置）。
> **强烈建议用透明背景的 PNG**，否则会看到白色方块。

## 二、图片的朝向约定

游戏把每张图当作"**默认朝右**"来用：

- 蛇头朝上时，图片会被自动旋转 90°；朝左 180°；朝下 270°。
- 蛇身、蛇尾也会跟着路径方向自动旋转，转弯处衔接更自然。
- 如果你的图是**朝上**画的（常见于竖版素材），把配置里的 `baseAngle` 改成 `-90` 就能纠正，不用重新作图。

## 三、进阶微调

打开 `snake/index.html`，搜索 `贴图皮肤配置`，找到这段：

```js
const SKIN = {
  scale: 1,                 // 相对格子大小的缩放，1 = 正好占满一格
  fit: 'contain',           // contain 保持比例留白 / fill 拉伸填满
  src: {
    head:  'img/head.png',
    body:  'img/body.png',
    tail:  'img/tail.png',
    apple: 'img/apple.png'
  },
  baseAngle: { head: 0, body: 0, tail: 0, apple: 0 },
  rotate:    { head: true, body: true, tail: true, apple: false }
};
```

常用调整：

- **图片显得太小 / 想出头一点** → 把 `scale` 改成 `1.1` ~ `1.25`
- **图片被裁掉或比例怪** → 把 `fit` 改成 `'fill'`（会拉伸填满格子）
- **图片方向不对** → 改 `baseAngle`：`0` 朝右、`90` 朝下、`180` 朝左、`-90` 朝上
- **不想要旋转** → 把 `rotate` 里对应项改成 `false`
- **文件名不一样** → 直接改 `src` 里的路径即可
- **想临时关掉某张图** → 把对应值改成 `''`（空字符串），该部位就退回内置矢量画法

## 四、容错说明

- 任何一张图**缺失或加载失败**时，只有那一个部位会退回原来的矢量画法，游戏照常能玩，不会白屏或报错。
- 如果你用"双击 HTML 文件"的方式打开（`file://` 协议），个别浏览器（如 Firefox）会拦截本地图片。遇到图片不显示时，换用本地服务器打开：

```bash
cd snake
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 五、附赠：占位图生成脚本

`_make_placeholders.py` 是生成当前这套示例贴图的脚本（需要 Pillow）。
如果你想重新生成一套干净的基础图再自己改造，可以运行：

```bash
python _make_placeholders.py
```

它会覆盖 `img/` 下的 4 张 PNG，**请先备份你自己的图**。
