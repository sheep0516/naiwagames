2048 数字图片说明
=================

命名规则
--------
0.png ~ 9.png，一位数字一张图。
方块上的数值是按位取图拼出来的，例如：
    128  → 1.png + 2.png + 8.png
    2048 → 2.png + 0.png + 4.png + 8.png

图片要求
--------
- 必须透明背景（这套 121×149 的 RGBA 图就是）。白底的图会在彩色方块上
  留下一个白色方块，很难看。
- 尺寸随意，程序按高度等比缩放。同一套图的长宽比接近会更整齐。
- 也支持 .jpg / .jpeg / .webp / .svg，按这个顺序探测（png 找不到才试 jpg 等）。
  但 jpg 没有透明通道，一般不适合。

当前缺哪几张
------------
这套图只有 0 1 2 3 4 5 6 8，缺 7 和 9。
缺的那一位会让**整个数值**退回内置文字（不是只把那一位换成文字，避免图字混排），
所以下面这些数会显示成普通文字：
    4096  8192  （含 9）
    32768 131072  （含 7）
把 7.png、9.png 按同样规格补进来即可自动生效，不用改代码。

显示尺寸
--------
单个字符的高度 = 格子边长 × 0.74；
整个数值的宽度上限 = 格子边长 × 0.90，所以位数越多字符越小
（保证 4 位数的 2048 不会顶出格子）。
想调大小，改 index.html 里的 DIGIT_MAX_H / DIGIT_MAX_W。

关掉图片
--------
index.html 顶部搜「自定义数字图片」，把 USE_IMAGES 改成 false，
方块就全部用内置文字，图片留着也不会被读取。

常见问题
--------
- 图片完全不显示：文件名必须是纯数字（0.png，不是「数字0.png」或「0 (1).png」），
  并且相对 index.html 的位置是 img/0.png。
- 只有部分数值是图片：说明缺位，见上面「当前缺哪几张」。
- 图看着糊：canvas 已经开了高质量缩放，如果还糊就是原图太小，换大一点的图。
