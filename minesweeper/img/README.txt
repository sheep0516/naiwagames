扫雷 · img 素材说明
========================================

目录内容
----------------------------------------
雷.png       你放进来的原始素材（128×128，RGBA，已经是透明底）
mine.png     游戏实际加载的雷贴图 —— 与 雷.png 内容相同，只是换成
             纯 ASCII 文件名，避免中文路径在 file:// 下的编码问题

游戏里加载哪个文件
----------------------------------------
index.html 顶部「雷的贴图」配置块里的 MINE_IMG，默认 'img/mine.png'。
· 想关掉贴图、改回内置的矢量雷（圆身 + 8 根刺）：把 MINE_IMG 改成 ''
· 想调整大小：改 MINE_RATIO（贴图边长 = 格子边长 × 该值，默认 0.94。
  贴图是正方形、以格心居中绘制，数值越大越顶格）
文件不存在或加载失败时会静默退回矢量雷，不会白图或报错。

贴图只影响"长什么样"
----------------------------------------
贴图**不参与任何判定** —— 雷的位置、输赢、插旗全都只看 mine 数组。
所以换图不会改变游戏难度，也不会让自测的雷数断言失效。

改了素材怎么办
----------------------------------------
把新图命名成 雷.png 放进本目录，然后：

· 新图**本来就是透明底**（推荐，和现在这张一样）：
  直接复制一份成运行时版本即可 ——

      cp img/雷.png img/mine.png

· 新图是**白底 / 不透明底**（画出来会带一个白方块）：
  必须先离线把白底去掉，再进游戏 ——

      node ../bricks/.timg.js --clean img/雷.png img/mine.png

  （浏览器在 file:// 下把本地图片画进 canvas 之后画布会被 taint，
   getImageData 抛 SecurityError，所以**运行时抠白底这条路走不通**，
   只能离线先处理好。）

先体检、看看素材什么情况（透明度 / 四角 alpha / 不透明包围盒）：

      node ../bricks/.timg.js img/雷.png

去完白底想肉眼验收有没有残留白边，把结果叠到深色底上出预览图：

      node ../bricks/.timg.js --preview img/mine.png preview.png 2a4a3a

常见问题
----------------------------------------
· 格子里看着发灰、看不清：贴图底色是亮黄，在浅色格底上对比一般，
  可以把 index.html 里 drawMine 的兜底底色 #e3efe8 调深一点再试。
· 角色上下被切掉：素材角色顶到画布上下边（当前这张 y 占满 0~127），
  把 MINE_RATIO 调小（比如 0.88）即可留出边距。
· 换素材后游戏里没变化：浏览器缓存了旧图片，强刷（Ctrl+F5）即可。
