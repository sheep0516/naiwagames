========================================================
 合成大西瓜 · 自定义图片说明（把图片放进本文件夹即可生效）
========================================================

把图片直接放进 img/ 文件夹，刷新页面就会自动替换成你的图。
找不到图片的水果会自动退回内置矢量水果，不会报错、不会白屏。

★ 换图只改变「外观」，碰撞体积（半径）完全不变 —— 玩法、手感、
  判负线、合成规则都不受任何影响。


--------------------------------------------------------
一、命名方式（三种任选，也可以混用）
--------------------------------------------------------
方式 A：按编号（推荐，最不容易搞错）
   1.png   2.png   3.png  ...  11.png
   分别对应 11 种水果，编号顺序就是下方对照表的顺序。

方式 B：按英文名
   grape.png     cherry.png     orange.png    lemon.png
   kiwi.png      tomato.png     peach.png     pineapple.png
   coconut.png   halfmelon.png  watermelon.png

方式 C：按中文名
   葡萄.png  樱桃.png  橘子.png  柠檬.png  猕猴桃.png  番茄.png
   桃子.png  菠萝.png  椰子.png  半个西瓜.png  大西瓜.png

扩展名支持 png / jpg / jpeg / webp / svg / gif，大小写随意。
查找顺序：先按「英文名」找 → 再按「中文名」找 → 最后按「编号」找。

--------------------------------------------------------
三、图片怎么做最好看
--------------------------------------------------------
* 正方形图（长宽比 1:1）效果最好，默认会「裁切铺满」整个圆球。
* 尺寸建议 256×256 左右，再大只是浪费体积（内部会自动压缩缓存）。
* 想要「正好是个球」：用方形图，或方形底 + 主体居中。
* 想要「完整显示整张图、不裁切」：见下方 IMG_FIT。
* 图片外面会自动加一圈很淡的描边和底部投影，让球更有立体感，
  不需要可以关掉（见下方 IMG_RING / IMG_SHADOW）。
* 用了自己的图，水果自带的「眼睛+嘴」表情就不会画了 —— 图片里
  想带表情自己画进图里即可。


--------------------------------------------------------
四、想调样式：打开 index.html 搜索「自定义图片配置」
--------------------------------------------------------
  USE_IMAGES = true     关掉图片用内置矢量水果（false）
  IMG_DIR    = 'img/'   图片目录，改成别的文件夹也可以
  IMG_EXTS   = [...]    扩展名探测顺序，比如想让 jpg 优先就往前挪
  IMG_FIT    = 'cover'  图片填充方式
                        'cover'   裁切铺满整个圆（默认，最像「球」）
                        'contain' 整张图完整显示，不裁切（可能留白）
  IMG_SCALE  = 1.0      图片相对碰撞圆的缩放，只影响外观
                        图里留白多可以调大到 1.1 ~ 1.3 撑满
  IMG_SHADOW = 0.16     底部投影强度，0 = 关闭
  IMG_RING   = 0.20     外圈描边强度，0 = 关闭

  改完保存，刷新页面即生效。


--------------------------------------------------------
五、常见问题
--------------------------------------------------------
Q：换了图片没变化？
A：浏览器缓存了旧图。按 Ctrl + F5（Mac 是 Cmd + Shift + R）强制刷新。

Q：图片不显示，还是原来的水果？
A：按 F12 打开控制台，会打印「已加载自定义图片 N/11：…」以及每个
   图片的 404 记录。逐项确认：
   · 文件名和扩展名完全一致（Windows 默认隐藏扩展名，可能出现
     实际文件名是 1.png.png 的情况）
   · 图片确实在 img/ 文件夹里（不是 img/img/ 里面）
   · 编号别搞错：1.png 是最小的葡萄，11.png 才是大西瓜

Q：用双击打开的方式，图片能加载吗？
A：可以。图片和网页在同一个文件夹里，不受跨域限制。
   如果个别浏览器拦截，用本地服务器打开（VS Code 的 Live Server 等）。

Q：能不能只换其中几个球？
A：可以。只放你想替换的那几张图，其余水果自动用内置矢量图，
   混搭完全没问题。

Q：为什么大图也是圆的，我的长图两边被切掉了？
A：默认 IMG_FIT = 'cover' 会裁切铺满圆形。不想裁切就改成
   'contain'（整图完整显示）。
