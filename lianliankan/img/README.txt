========================================================
 连连看 · 自定义图片说明（把图片放进本文件夹即可生效）
========================================================

把图片直接放进 img/ 文件夹，刷新页面就会自动替换成你的图。
找不到图片的方块会自动退回内置矢量图标，不会报错、不会白屏。

--------------------------------------------------------
一、命名方式（两种任选，也可以混用）
--------------------------------------------------------
方式 A：按编号（推荐，最不容易搞错）
   1.png   2.png   3.png   4.png   5.png   6.png   7.png   8.png
   分别对应 8 种方块，编号顺序就是下方对照表的顺序。

方式 B：按名字
   apple.png  star.png  heart.png  drop.png
   leaf.png   flower.png gem.png   sun.png

扩展名支持 png / jpg / jpeg / webp / svg，大小写随意。
查找顺序：先按「名字」找，找不到再按「编号」找。

--------------------------------------------------------
二、方块类型对照表（默认 8 种）
--------------------------------------------------------
   编号 1  apple    苹果     原图：红色苹果
   编号 2  star     星星     原图：橙色五角星
   编号 3  heart    爱心     原图：粉色爱心
   编号 4  drop     水滴     原图：蓝色水滴
   编号 5  leaf     叶子     原图：绿色叶片
   编号 6  flower   小花     原图：紫色五瓣花
   编号 7  gem      宝石     原图：青色钻石
   编号 8  sun      太阳     原图：橙色太阳

--------------------------------------------------------
三、图片怎么做最好看
--------------------------------------------------------
* 正方形图（长宽比 1:1）效果最好，会自动铺满整个方块
* 尺寸建议 96×96 或 128×128 以上，再大只是浪费体积
* 背景透明的 PNG 效果最好（会露出方块淡色底）
* 非正方形的图默认「裁切填满」，想完整显示见下方 IMG_FIT

--------------------------------------------------------
四、想改数量 / 样式：打开 index.html 搜索「自定义图片配置」
--------------------------------------------------------
  TYPE_COUNT = 8        方块种类数，有几张图就填几（2 ~ 16）
                        例如只有 4 张图就填 4
  IMG_CARD   = true     图片外面是否保留淡色圆角底板
                        false = 只显示图片本体，不带底色边框
  IMG_FIT    = 'cover'  图片填充方式
                        'cover'   裁切填满（默认，方形最饱满）
                        'contain' 完整显示整张图（可能留白）
  IMG_DIR    = 'img/'   图片目录，改成别的文件夹也可以
  USE_IMAGES = false    关掉图片，回到内置矢量图标

  提示：图片命名要和 TYPE_COUNT 对得上。比如 TYPE_COUNT 改成 4，
  那就只读 1~4 这四种（或 apple、star、heart、drop 四个名字）。

--------------------------------------------------------
五、常见问题
--------------------------------------------------------
Q：换了图片没变化？
A：浏览器缓存了旧图。按 Ctrl + F5（Mac 是 Cmd + Shift + R）强制刷新。

Q：图片不显示，还是原来的图标？
A：按 F12 打开控制台看有没有 404；确认文件名和扩展名完全一致
   （Windows 默认隐藏扩展名，可能实际是 1.png.png）；
   确认图片确实在 img/ 文件夹里（不是 img/img/ 里面）。

Q：用双击打开的方式，图片能加载吗？
A：可以，图片和网页在同一个文件夹里没有跨域限制。
   如果个别浏览器拦截，用本地服务器打开（VS Code 的 Live Server 等）即可。

Q：我想放 12 种图片？
A：把 index.html 里 TYPE_COUNT 改成 12，图片命名为 1.png ~ 12.png 即可。
   第 9 种及以后没有内置矢量图标，必须配图片，否则显示为圆点占位。
